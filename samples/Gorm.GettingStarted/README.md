# Your first GORM graph

This is the **source of truth** for the first-run tutorial. It is a real .NET 10 console application referencing the **published** `GORM 3.1.0-preview.1` NuGet package. It does not reference the library's source project and requires no SQL Server, Docker, account, server or API key.

## Run it

From the repository root with the .NET 10 SDK:

```bash
dotnet run --project samples/Gorm.GettingStarted/Gorm.GettingStarted.csproj -c Release
```

Expected results include:

```text
Alice works on GORM.
SQL generated by GORM (not executed against SQL Server in this sample):
...
GORM getting-started sample passed.
```

The application creates two graph nodes, connects them through a typed edge, persists to an in-memory GORM store, traverses to the project, and calls GORM's **actual** `Explain()` translator to display the SQL Server Graph SQL shape. Its checks deliberately fail the process if graph traversal or translation stops working.

The in-memory execution is for a zero-setup first experience. It **does not** prove SQL Server provider parity or execute the generated SQL. For real persistence use the separate [SQL Server Graph demo](../Gorm.Demo/README.md), the database-first schema script and the [Testcontainers integration tests](../../tests/Gorm.SqlServer.Tests/README.md).

## Start from an empty application

```bash
dotnet new console --framework net10.0 -n MyFirstGraph
cd MyFirstGraph
dotnet add package GORM --version 3.1.0-preview.1
```

Then replace your `Program.cs` with the contents of [this sample's Program.cs](Program.cs) and run `dotnet run`. These commands use only the public package; no repository checkout is necessary to develop a project.

## CI contract

The regular [GORM .NET validation](../../.github/workflows/build-gorm.yml) builds and **runs this exact sample** on every pull request. The standalone project intentionally pins the currently published preview; future previews should update it explicitly after NuGet.org installation has been verified.

The [web Playground](https://pjotrcasteel.github.io/GORM/playground.html) currently uses an illustrative browser preview translator, **not** GORM's compiled runtime. The console sample's `Explain()` output is authoritative for the library version it references.
