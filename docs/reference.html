API REFERENCE

The documented core surface at a glance.

This page describes the public GORM .NET 10 preview's core API. Verify full signatures and constraints against the source and the published package; this hand-written overview is not a complete generated API reference.

Reference status

Core types and operators below are available in the current source; the exact API contracts are defined by the NuGet assembly. Advanced capabilities remain experimental until their contracts are tested and documented.

CORE TYPES

Graph entities

Node

Base graph entity for domain objects that participate as SQL Server Graph nodes.

Documented convention: Id is identity.
Edge

Base graph entity for typed directed relationships between nodes.

Relationship types may carry their own properties.
GraphSet<TNode>

Typed LINQ query surface for a configured node type.

Refer to the current NuGet assembly and source for exact generic constraints.
QUERY ROOT

Set<TNode>()

context.Set<ServiceNode>()

Starts a typed node-root query. Standard LINQ expressions can filter, project, order, page and aggregate before graph-specific operations are applied.

TRAVERSAL

Outgoing<TEdge, TTarget>()

context.Set<ServiceNode>()
    .Outgoing<DependsOnEdge, ServiceNode>()

Moves from the current node query to connected target nodes through an outgoing typed relationship.

TRAVERSAL

Incoming<TEdge, TSource>()

context.Set<ServiceNode>()
    .Incoming<DependsOnEdge, ServiceNode>()

Moves from the current target nodes to connected source nodes through an incoming typed relationship.

RELATIONSHIP LOADING

Include(...) and ThenInclude(...)

context.Set<PersonNode>()
    .Include(x => x.Projects)

Requests relationship-aware materialization of navigation properties. Use this when the connected object graph is the desired result shape rather than a path-oriented traversal.

IDENTITY FILTERS

WhereId(...) / WhereIds(...)

Documented convenience filters for node identity lookups and identity sets.

var service = await context.Set<ServiceNode>()
    .WhereId(serviceId)
    .SingleAsync();
LINQ

Filters, projections, paging and aggregates

Where(...)Filter node or traversal results.
Select(...)Project query results.
OrderBy(...)Apply deterministic ordering.
Skip(...) / Take(...)Bound or page query results.
AggregatesExecute supported aggregate operations through the provider.
TEMPORAL

AsOf(...), Current() and history ranges

AsOf(...)

Queries graph state at a point in time.

Current()

Restricts a temporal-capable graph query to current state.

Range queries

Inspect graph history over a period for history, diff and incident scenarios.

EXECUTION

Async materialization

ToListAsync()Materialize a sequence.
SingleAsync()Require a single result.
FirstAsync()Materialize the first result where supported.
CountAsync()Execute a count aggregate where supported.
PROVIDERS

SQL Server Graph and in-memory execution

SQL SERVER GRAPH

Production persistence semantics: graph tables, MATCH translation, temporal behavior and provider-specific database behavior.

IN-MEMORY

Fast deterministic execution for unit tests and BDD scenarios using the same graph model, without claiming provider equivalence.

ADVANCED SURFACE

Why Graph Intelligence and ChangeSet are not listed as stable methods here

The GORM source contains Graph Intelligence, Digital Twin, GraphRAG, Helix and ChangeSet capabilities. Their responsibilities are documented, but the precise available APIs must be confirmed against the preview NuGet assembly before usage.
