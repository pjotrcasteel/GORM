API REFERENCE

The GORM surface at a glance.

This page documents the intended public API shape represented by the current GORM documentation. The implementation source is still pending migration, so signatures should be validated against the migrated code before package publication.

CORE TYPES

Graph entities

Node

Base graph entity for domain objects that participate as SQL Server Graph nodes.

Default convention: Id is identity.
Edge

Base graph entity for typed directed relationships between nodes.

May carry relationship properties.
GraphSet<TNode>

Typed query root for a configured node type.

LINQ provider entry point.
QUERY ROOT

Set<TNode>()

GraphSet<TNode> Set<TNode>();

Starts a typed node query. Standard LINQ expressions can filter, project, order, page and aggregate before graph-specific operations are applied.

TRAVERSAL

Outgoing<TEdge, TTarget>()

query.Outgoing<TEdge, TTarget>()

Traverses from the current node query to target nodes through outgoing edges of TEdge.

RequiresTEdge : EdgeReturnsGraph query of TTarget
TRAVERSAL

Incoming<TEdge, TSource>()

query.Incoming<TEdge, TSource>()

Traverses from the current target node query to source nodes that point to it through TEdge.

RELATIONSHIP LOADING

Include(...) and ThenInclude(...)

context.Set<PersonNode>()
    .Include(x => x.Projects)
    .ThenInclude(x => x.Owner)

Requests relationship-aware materialization of navigation properties. Use for object graphs rather than path-oriented traversal.

CONVENIENCE FILTERS

WhereId(...) / WhereIds(...)

Convenience predicates for node identity lookups, including sets of ids where supported by the provider.

var service = await context.Set<ServiceNode>()
    .WhereId(serviceId)
    .SingleAsync();
TEMPORAL

AsOf(...), Current() and ranges

AsOf(DateTimeOffset)

Queries graph state at a point in time.

Current()

Restricts a temporal-capable query to current state.

Temporal range

Queries state over a period for history and diff scenarios.

EXECUTION

Async materialization

ToListAsync()Materialize a sequence.
SingleAsync()Require exactly one result.
FirstAsync()Materialize the first result.
CountAsync()Execute a count aggregate.
GRAPH INTELLIGENCE

Projection and analysis APIs

Graph Intelligence consumes configured GORM graph state for algorithms such as impact, routing, centrality, components and communities. Analysis remains read-only unless application code explicitly applies a mutation.

WRITE PLANNING

ChangeSet compiler

The ChangeSet surface is intended to expose ordered graph persistence work before execution, including conflicts and rollback semantics.

var plan = context.ChangeSet.Preview();
await context.SaveChangesAsync();
PROVIDERS

SQL Server Graph and in-memory execution

SQL SERVER GRAPH

Production provider for graph persistence, MATCH translation, temporal behavior and provider-specific concurrency semantics.

IN-MEMORY

Fast deterministic execution for unit tests and BDD scenarios using the same configured graph model.

STATUS

Reference stability

Pre-publication reference

This reference captures the intended public shape from the current implementation materials. Once source migration lands, this page should be generated or validated directly against public symbols so documentation drift becomes a CI failure.
