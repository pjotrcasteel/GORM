A graph-first persistence model

Relationships stop being hidden join plumbing.

GORM promotes graph intent into the API: traverse relationships directly when the path matters, or load navigation properties when the object graph is the more useful result shape.

TRAVERSEOutgoing<TEdge, TTarget>()

Move from one typed node set to another through an explicit edge type.

LOADInclude(...) / ThenInclude(...)

Materialize related graph state when you want a connected object graph.

TIMEAsOf(...) / Current()

Inspect connected state at a moment in time instead of only current rows.

TESTIn-memory execution

Use the same graph model in fast deterministic tests while keeping provider integration tests explicit.
