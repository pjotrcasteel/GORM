GORM DOCUMENTATION

Build graph-shaped applications without hiding the graph.

GORM is a strongly typed graph ORM for .NET and SQL Server Graph. Start with ordinary CLR types, express relationship direction explicitly, inspect generated SQL and use the same graph model for temporal inspection and fast tests.

QUICKSTART

Build your first graph in three steps

1

Define two nodes

Nodes remain ordinary domain types.

public sealed class PersonNode : Node
{
    public string Name { get; set; } = string.Empty;
}

public sealed class ProjectNode : Node
{
    public string Name { get; set; } = string.Empty;
}
2

Define the relationship

The edge is typed and may carry its own data.

public sealed class WorksOnEdge : Edge
{
    public bool IsPrimary { get; set; }
}
3

Traverse it

The direction and edge type become visible in application code.

var projects = await context.Set<PersonNode>()
    .Where(x => x.Id == personId)
    .Outgoing<WorksOnEdge, ProjectNode>()
    .ToListAsync();

MENTAL MODEL

Use the right tool for the question

Where / Select / OrderByAsk questions about scalar data on a node set.
Outgoing / IncomingAsk which nodes are connected through a typed directed relationship.
Include / ThenIncludeMaterialize related graph state as an object graph.
AsOf / CurrentMove graph inspection through time.
Graph IntelligenceDerive impact, routing, components or other graph insight.
ChangeSetInspect and execute graph persistence work.
INSTALLATION

Package publication follows source migration

The public repository intentionally establishes the GORM product identity and documentation before the existing implementation source is migrated, renamed and validated.

// Intended package shape after publication
dotnet add package GORM
Repository preview

The command above documents the intended public package shape; it is not a claim that the NuGet package has already been published.
