QUICKSTART

Build your first graph in three steps

1

Define two nodes

Nodes remain ordinary domain types.

public sealed class PersonNode : Node
{
    public string Name { get; set; } = string.Empty;
}

public sealed class ProjectNode : Node
{
    public string Name { get; set; } = string.Empty;
}
2

Define the relationship

The edge is typed and may carry its own data.

public sealed class WorksOnEdge : Edge
{
    public bool IsPrimary { get; set; }
}
3

Traverse it

The direction and edge type become visible in application code.

var projects = await context.Set<PersonNode>()
    .Where(x => x.Id == personId)
    .Outgoing<WorksOnEdge, ProjectNode>()
    .ToListAsync();

MENTAL MODEL

Use the right tool for the question

Where / Select / OrderByAsk questions about scalar data on a node set.
Outgoing / IncomingAsk which nodes are connected through a typed directed relationship.
Include / ThenIncludeMaterialize related graph state as an object graph.
AsOf / CurrentMove graph inspection through time.
Graph IntelligenceDerive impact, routing, components or other graph insight.
ChangeSetMake graph persistence work inspectable before execution.
INSTALLATION

Install the published .NET 10 preview

GORM 3.1.0-preview.1 is publicly available on NuGet.org. Create a console application, install GORM, and follow the working, package-only tutorial:

dotnet new console --framework net10.0 -n MyFirstGraph
cd MyFirstGraph
dotnet add package GORM --version 3.1.0-preview.1

Copy the verified Program.cs into your new project, then run dotnet run. The example uses an in-memory store and prints SQL generated by GORM's real translator.

What's real and what's a preview?

The NuGet-based console example runs actual GORM code. The website's interactive LINQ Playground still approximates SQL in JavaScript; it is not the compiled translator. Real SQL Server persistence requires a database-first schema.
