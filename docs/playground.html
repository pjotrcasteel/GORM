WHAT THIS TEACHES

Make graph intent visible.

The left side is application intent: node root, predicates, direction and edge type. The right side exposes the persistence concepts beneath it: source and target tables, edge table, MATCH, predicates and temporal clauses.

WHERE THIS GOES NEXT

Replace preview translation with GORM itself.

After the source migration, the ideal playground path is a small sandboxed .NET/WASM or server-backed compiler endpoint that uses the actual GORM expression visitor and SQL generator. Then the documentation examples become executable contract tests against the real translator.
