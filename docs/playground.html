WHY THIS MATTERS

Graph intent should be inspectable.

The query anatomy separates node roots, scalar predicates, traversal direction, edge types, targets, temporal context and limits. The inspector then shows which translation stages and parameters are involved.

SHARE EXACT REPRODUCTIONS

Every custom query can become a permalink.

Use Share query to encode the editor state in the URL. That makes examples usable in docs, issues and PR discussions without pretending the generated SQL is an authoritative runtime result.

RUNTIME INTEGRATION CONTRACT

The UI depends on one translator contract.

The playground shell owns editor state and sharing. The runtime owns translation and rendering. A future GORM runtime adapter only needs metadata plus an async-compatible translate(query) function, while the example contracts continuously verify the documented behavior.

window.GormPlaygroundEngine = {
    metadata: {
        id: "gorm-runtime",
        label: "GORM runtime",
        version: "1.0.0",
        authoritative: true,
        execution: "sandboxed .NET"
    },
    translate: async query => ({ ok, sql, notes, model })
};
