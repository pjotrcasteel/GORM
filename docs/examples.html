TRAVERSAL

Connected-data queries

ONE HOP · OUTGOING

Find a person's projects

context.Set<PersonNode>()
    .Where(x => x.Id == personId)
    .Outgoing<WorksOnEdge, ProjectNode>()
Run example →
ONE HOP · INCOMING

Find database dependents

context.Set<ServiceNode>()
    .Where(x => x.Id == databaseId)
    .Incoming<DependsOnEdge, ServiceNode>()
Run example →
TWO HOPS

Follow a routed dependency

context.Set<ServiceNode>()
    .Where(x => x.Id == gatewayId)
    .Outgoing<RoutesToEdge, ServiceNode>()
    .Outgoing<DependsOnEdge, DatabaseNode>()
Run example →
LINQ

Filtering and result shaping

FILTER + PAGE

Page active services

context.Set<ServiceNode>()
    .Where(x => x.State == ServiceState.Active)
    .OrderBy(x => x.Name)
    .Skip(20)
    .Take(25)
Run example →
TEMPORAL

Inspect an incident snapshot

context.Set<ServiceNode>()
    .AsOf(incidentStartedAt)
    .Where(x => x.Name == serviceName)
Run example →
RELATED DATA

Materialize a relationship

context.Set<PersonNode>()
    .Include(x => x.Projects)
    .SingleAsync(x => x.Id == personId)
