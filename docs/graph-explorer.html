WHY OUTGOING?

Direction is part of the question.

If the current node is the source of an edge, the explorer emits Outgoing<TEdge, TTarget>(). If it is the target, the same relationship becomes an incoming traversal.

WHY TYPE THE EDGE?

The relationship carries domain meaning.

GORM does not reduce the path to anonymous joins. Your own edge types remain visible in application code and in the SQL Server Graph query shape.

WHY DESIGN HERE?

One model drives every view.

The designer, topology canvas, traversal builder and query outputs all consume the same model. Editing topology therefore immediately changes the questions you can ask.
