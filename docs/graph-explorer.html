WHY OUTGOING?

Direction is part of the question.

If the current node is the source of an edge, the explorer emits Outgoing<TEdge, TTarget>(). If it is the target, the same relationship becomes an incoming traversal.

WHY TYPE THE EDGE?

The relationship carries domain meaning.

GORM does not reduce the path to anonymous joins. RoutesToEdge, DependsOnEdge and other edge types remain visible in application code and SQL shape.

WHY INSPECT SQL?

Graph intent should remain explainable.

The generated shape shows which node and edge tables participate and how MATCH represents every hop. The production translator remains the authority once migrated.
